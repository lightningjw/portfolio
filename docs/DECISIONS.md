# DECISIONS: Portfolio rebuild

Append one line per decision: date, decision, short reason. Newest at the bottom.

- 2026-11-14: Rebuild rather than restyle: Vite + React + TS + Tailwind + Motion, GitHub Pages via Actions. Reason: CRA is deprecated and the existing content is placeholder.
- 2026-11-14: Sports theme expressed through data viz and field geometry, not mascots or clip-art. Reason: it signals sports ML engineer, not template.
- 2026-11-14: Site copy comes only from PORTFOLIO_BRIEF.md, written in the Full Time Job Search project. Reason: one reviewed checkpoint for what goes public.
- 2026-11-14: Positioning targets the ML engineer / data scientist role family with a baseball-analytics edge, not individual postings.
- 2026-11-14: Contact form backend removed; replaced with mailto + GitHub/LinkedIn.
- 2026-11-15: Visual direction is B, Hand-Operated: manual-scoreboard world, board green #10271D ground, chalk numerals in inset tiles, gold #F2B632 accent, Big Shoulders Display + Archivo. Reason: preferred palette, type, hero and box score card.
- 2026-11-15: Hero is the binned BSN shot chart on a FIBA half court, from the BSN Shot Outcome Prediction project. Data comes from lightningjw/Guaynabo-Mets-Reports and is redrawn in the portfolio's design system, not copied. Aggregate BSN and SynergySports data is cleared to show publicly.
- 2026-11-15: Sport filter is All / Baseball / Basketball / Motorsport / Core ML, replacing All / Soccer / Basketball / Baseball. Reason: matches the projects that exist.
- 2026-11-15: Motion rule amended: stroke-drawn lines are allowed in the hero only; everything else stays transform and opacity.
- 2026-11-15: TODO placeholders are visible in development and PR preview builds and hidden on the deployed site. Blank result tiles are acceptable; content gets filled in after the rebuild.
- 2026-11-15: Degree is BSE in Computer Science, not BS. Bio in PORTFOLIO_BRIEF.md updated.
- 2026-11-15: DESIGN.md approved as written and is the visual source of truth. Single dark theme, no light mode.
- 2026-11-15: Surfaces are board #10271D, board-deep #0A1A13 (recessed slots), board-raised #17352A (cards). Text is chalk #F1EBDD, chalk-dim #B4C0B1, chalk-faint #8FA394 (not allowed on raised surfaces).
- 2026-11-15: Gold is reserved for the primary button, active filter, focus ring, link underline and the top chart bin. Stat numerals are chalk.
- 2026-11-15: Stats render one character per plate in a recessed tile, max four plates, unit outside the plates. A blank result is two empty plates.
- 2026-11-15: Sport accents are an 8px swatch only: baseball #D0714A, basketball #CFA77E, motorsport #8FA6B2, Core ML #D9D2C0.
- 2026-11-15: Labels use Archivo at wdth 88, weight 600, uppercase. Big Shoulders Display is headings and numerals only, never below 20px.
- 2026-11-15: Radii stop at 3px. No drop shadows; depth is inset only.
- 2026-11-15: Motion tokens set (80 / 140 / 220 / 260 / 600ms, no springs). Hero sequence is 1,800ms in five beats, once per load. Hover colour changes are instant.
- 2026-11-15: Hero chart is non-interactive in v1.
- 2026-11-15: Field markings limited to four (court in hero, diamond, centre circle, baseline), max three outside the hero, never behind paragraph text.
- 2026-11-15: Skills render as rectangular non-interactive plates. Nav collapses to a labelled MENU button below 1024px.
- 2026-11-15: Eldridge card tile is 95.6 MPH, descriptor "Avg exit velocity, 37-PA debut". Reason: fastest-stabilizing metric at that sample, legible to non-baseball readers, and the figure reconciled to Baseball Savant.
- 2026-11-15: Each project in PORTFOLIO_BRIEF.md gets a Card method line and a Card tile field, derived from its Method and Headline result.
- 2026-11-15: Fonts verified. Use the Archivo file with both wght and wdth axes. Big Shoulders Display has no tabular figures, so its numerals are aligned by plates only.
- 2026-11-15: Hero data is the scraped BSN shot-location file (20,716 shots, 12 teams, games from 3 April to 6 June 2024), not Guaynabo-Mets-Reports, which has no shot coordinates. The raw file is never committed; only src/data/heroShotBins.json (bin totals, built by scripts/build_shot_bins.py) is public.
- 2026-11-15: Hero bins are 0.5m hexagons with a 10-attempt minimum (194 bins). Colour is points per shot in five fixed classes; size is attempts on a square-root scale capped at 310.
- 2026-11-15: Hero caption uses the shot-location file's own counts, not the 34K+ figure, which belongs to the model's training data.
- 2026-11-15: Phase 3 build is in PR #3 (branch redesign/v2). Tokens live only in src/styles/tokens.css; lint fails on raw hex, Tailwind arbitrary values or literal px/rem/ms elsewhere in src/.
- 2026-11-15: TODO placeholders are off in every build and opt-in with VITE_SHOW_TODOS=true. Supersedes "visible in development and PR preview builds". Reason: TODO text should never render by accident.
- 2026-11-15: Missing content is acceptable for now: hero source credit, five project links, the GPT project result and the contact sentence stay hidden until PORTFOLIO_BRIEF.md supplies them.
- 2026-11-15: Result tile is 200px wide from 768px up; the 168px width at 1024px is dropped. Reason: four plates plus a unit do not fit in 168px.
- 2026-11-15: Below 768px the result tile stays 96px tall with the descriptor beside the plates, not under them.
- 2026-11-15: Education renders inside the Experience section using the experience entry component.
- 2026-11-15: Footer uses a plain 1px rule; the baseline marking appears only above Contact. Reason: keeps field markings at three outside the hero.
- 2026-11-15: The baseline marking's ticks are the real lines that meet a FIBA baseline (sidelines, three-point corner lines, key edges), not hash marks.
- 2026-11-15: The diamond marking is drawn whole in the Projects header band, not cropped.
- 2026-11-15: Filter count tile always shows two plates; a single-digit count leaves the leading plate empty.
- 2026-11-15: Hero sequence is CSS keyframes driven by the motion tokens; Motion handles the filter, card reflow, count tile, menu and section entrances. During the draw, court line width comes from the measured scale instead of non-scaling-stroke.
- 2026-11-15: The no-JavaScript rule for the hero is not met by a client-rendered build; a prerender step is scheduled for Phase 6.
- 2026-11-15: The site serves 4:5 WebP crops of the portrait (480px and 960px wide); portrait.JPG stays in the repo unmodified.
- 2026-11-15: ESLint pinned to 9 until eslint-plugin-jsx-a11y supports 10.
- 2026-11-15: GitHub Pages source switched to GitHub Actions; the gh-pages branch is no longer used.
- 2026-11-15: Phase 4 polish is in a new PR from redesign/v2; PR #3 was merged before Phase 4 started.
- 2026-11-15: Hero bins plot in by ring opacity only; the per-bin scale is dropped. Reason: DESIGN.md's performance gate. At 4x CPU throttling the 194 per-bin animations cost a 70 to 90ms style recalculation at the start and dropped frames; ring-only measured 0 dropped at 4x and 6x.
- 2026-11-15: The hero sequence starts when the main thread is idle (500ms deadline) instead of inside the mount task. Reason: at 4x throttling beat 1 lost 10 to 13 of 54 frames to startup work.
- 2026-11-15: A newly active filter label and swatch cut to board after delay-filter-settle (200ms), once the gold plate has landed. It is a delayed hard cut, not a colour animation, so the transform-and-opacity rule stands. Reason: the label was board on board while the gold travelled.
- 2026-11-15: Under reduced motion the press scale and arrow nudge are removed outright, not just their transitions.
- 2026-11-15: Motion durations are parsed from the CSS tokens with their unit. Reason: the minifier turns 260ms into .26s and every Motion animation was finishing inside one frame in production.
- 2026-11-15: The mobile menu closes instantly on Escape; pointer closes keep the exit.
- 2026-11-15: Hover styles are gated on (hover: hover) and (pointer: fine).
- 2026-11-15: Exits use ease-out; the ease-in token is removed. Reason: ease-in delays the moment being watched.
- 2026-11-15: Press feedback is 160ms and scale 0.97. Supersedes 80ms and 0.98.
- 2026-11-15: Entering filter cards start after duration-fast (140ms), alongside the reflow, not after it.
- 2026-11-15: Motion rule amended: the filter's gold layer animates clip-path, the second exception after the hero's stroke-drawn lines. The gold is a clipped copy of the plate row, so labels change colour at the gold's edge. Supersedes the shared-layout plate and the 200ms delay-filter-settle cut.
- 2026-11-15: ease-in-out is cubic-bezier(0.77, 0, 0.175, 1). Supersedes 0.65, 0, 0.35, 1.
- 2026-11-15: Section stagger uses shrinking gaps (50, 40, 30, 20ms) instead of a uniform 40ms.
- 2026-11-16: Phase 6 verification is in a new PR from redesign/v2; PR #4 was merged before Phase 6 started.
- 2026-11-16: The social preview image is public/og.png, the hero captured at 1200x630 under reduced motion. Open Graph, Twitter card and canonical tags use the absolute URL https://lightningjw.github.io/portfolio/. Recapture og.png when the hero changes.
- 2026-11-16: TodoNote reads VITE_SHOW_TODOS itself so the bundler removes its "TODO" text from every default build. The field notes passed to todo() still ship as unrendered strings in the bundle.
- 2026-11-16: Desktop nav links draw their focus ring inside the box (ring-inset). Reason: at full nav height the offset ring's top edge fell outside the viewport.
